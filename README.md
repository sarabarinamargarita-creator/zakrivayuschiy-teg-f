# Проект «Закрывающий тег»

Ссылка на проект:

Учебный проект, посвященный пути студента на курсе веб-разработки. Это интерактивная страница-воспоминание с элементами ретро-игр, анимациями и адаптивной версткой.

## Технологии

- **HTML5** (семантическая верстка, тег `<dialog>`)
- **CSS3** (Grid, Flexbox, адаптивность через `clamp()` и медиазапросы, CSS-фильтры, градиенты, `mix-blend-mode`)
- **JavaScript** (работа с модальным окном, переключение класса `is-liked` для лайков)
- **Методология**: БЭМ (Блок, Элемент, Модификатор) для именования классов.

## ✨ Реализованный функционал

- **Адаптивная верстка**:
  - Плавное изменение размеров шрифтов и отступов на десктопе с помощью функции `clamp()`.
  - Отдельная мобильная версия для экранов до 375px (медиазапросы).
- **Сложный фиксированный фон**: Создан с помощью наложения нескольких `repeating-linear-gradient` и `linear-gradient`. Фон не прокручивается вместе со страницей.
- **Карточки с контентом**: 8 уникальных карточек с личными воспоминаниями, изображениями и лейблами.
- **CSS-фильтры**: На каждое изображение наложен уникальный фильтр (sepia, blur, grayscale, hue-rotate, invert, множественный фильтр) для передачи нужной эмоции.
- **Интерактивные элементы**:
  - **Кнопки**: Плавные ховер-эффекты с наезжающим фоном и режимом смешивания `mix-blend-mode: difference`.
  - **Анимация сердца**: При клике на сердечко оно закрашивается, масштабируется, и вокруг появляются искры (реализовано через `@keyframes` и класс `is-liked`).
- **Модальное окно**: Реализовано с использованием нативного тега `<dialog>`. Открывается по кнопке «Сохранить на память», закрывается по кнопке «ОК» или клику на фон.

## 📂 Структура проекта

- `index.html` - основная HTML-разметка.
- `styles/` - стили проекта:
  - `variables.css` - переменные (шрифты, цвета, градиент).
  - `globals.css` - глобальные стили (сброс отступов, box-sizing).
  - `style.css` - основная верстка и адаптивность.
  - `animations.css` - анимации и эффекты (ховеры, анимация сердца).
- `scripts/` - скрипты (логика модального окна и лайков).
- `images/` - папка с изображениями и гифками.
- `fonts/` - шрифты проекта.
- `svg/` - спрайты и SVG-иконки.
